# Regenerative economics

An established frame (Fullerton's Capital Institute and adjacent work) placing economies on a spectrum from **degenerative** to **regenerative**. Co-Goods reads the axis as fundamentally about *value distribution*: a business is extractive when it retains too much value instead of distributing it for renewal.

The POV argued through this topic: many nonlinear, at-scale businesses — social media the clearest case — are extractive precisely *because* their scale lets them retain enormous value rather than return it to the communities that create it. Co-goods is the counter-move — leverage the same nonlinear dynamics for regeneration.
