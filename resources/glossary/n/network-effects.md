# Network effects

A good shows **network effects** when each additional user adds value for the existing ones, so total value grows faster than the user count. They are the mechanism behind [[antirival-goods]] goods — value rising with shared use rather than falling with competition.

Co-Goods's wager is that network effects can be harnessed to *reduce* material throughput rather than drive extraction: by coordinating real demand, fewer and better physical things get made and actually used. That makes this an anchor topic — the established lens through which the co-goods POV on physical production is argued.
