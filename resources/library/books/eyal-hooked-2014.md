# Hooked: How to Build Habit-Forming Products

## Overview

Nir Eyal's *Hooked* (2014) lays out the **Hook model** — *trigger → action → variable reward → investment* — as the loop by which products become habits. It is a clear, operational account of how [[engagement]] is engineered.

## Notes

Read here as the cautionary, extractive face of engagement design: the same mechanics co-goods aims to turn toward genuine value. A useful contrast with [[antirivalness|antirival]] systems, where more participation makes the whole worth more rather than merely capturing attention.
