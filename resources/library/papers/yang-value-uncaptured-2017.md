# Value uncaptured perspective for sustainable business model innovation

## Overview

Yang, Evans, Vladimirova, and Rana (2017) propose **value uncaptured** as a lens for sustainable business-model innovation: value that *could* be created or captured but currently isn't. They distinguish four forms:

- **Value surplus** — value created but not required.
- **Value absence** — value required but not created.
- **Value missed** — value created and required, but not captured.
- **Value destroyed** — negative outcomes and waste.
