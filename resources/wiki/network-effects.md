# Network effects

## Summary

A product, service, or protocol becomes more valuable to each participant as more people use it — value grows with adoption rather than being consumed by it.

## Overview

Network effects are positive feedback loops in adoption: each additional user raises the value available to the others. They are commonly divided into:

- **Direct (same-side)** — value rises with the number of users of the same kind (a phone or messaging network).
- **Indirect (cross-side)** — value on one side rises with participation on another (a marketplace, where more buyers attract more sellers and vice versa).

They underpin standards, languages, and platforms, and are a primary source of "winner-take-most" dynamics.
